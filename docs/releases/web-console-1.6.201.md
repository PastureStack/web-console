# Web Console 1.6.201 / bridge 0.2.3

Web Console 1.6.201 and bridge 0.2.3 are
[published](https://github.com/PastureStack/web-console/releases/tag/1.6.201).
The release retains the original qualified CI bytes. All 13 public assets matched
their recorded SHA256 values. Dependencies and their graphs are unchanged apart
from the root package versions.

## Bounded client workflows

The twelve typed tools add stopped External Service creation with one selected
hostname/IP mode and separately reviewed endpoint changes. DNS Aliases are
created stopped and empty; binding local Service references needs a separate
human-approved plan. Advanced/remote links, incoming-consumer and cross-source
cleanup remain explicit limits.

Audit queries use typed Key/environment/time/decision filters and opaque
references through the fixed Engine/broker owner. Current actor, role, Key scope
and revision remain authoritative. Raw IDs, arbitrary URLs, private answers and
audit request/response payloads are not tool shortcuts. Payloads and export stay
in the existing human audit UI; querying metadata does not complete those flows.

Normal UI, session, Full/legacy permissions, human review, Catalog/Archive and
default-off opt-ins are preserved. These adapters need matching Engine
0.183.360 and the audit-query broker. Matching Engine / Server 560 qualification
and designated combined browser, role, cross-ID, layout and weak-model acceptance
remain pending. The designated `8080` QA deployment remains Server `v1.6.559` /
Web `1.6.200`; no new-domain runtime PASS is claimed. This release does not
complete all 243 baseline business groups or discovered operation overlays.
